# Skill: EmailFlare [NEXUS Hardened]
Description: Управление слоем рассылок через Cloudflare. Позволяет агентам отправлять отчеты, уведомления и маркетинговые письма.

## Когда использовать
- Для отправки отчетов о рендеринге в Solara.
- Для уведомления о завершении длинных задач NEXUS.
- При необходимости автоматизировать коммуникацию с внешними пользователями.

## Команды
- `/email`: Запуск дашборда и проверка статуса.
- `python PROJECT/emailflare/nexus_email_agent.py`: Отправка письма программно.

## Интеграция
- Базируется на Docker-контейнере `0xdps/emailflare`.
- Использует Cloudflare Email Sending API.
- Настройки хранятся в `PROJECT/emailflare/.env`.

## Шаблоны
EmailFlare содержит 50+ готовых шаблонов. Чтобы использовать их:
1. Зайдите в панель управления (http://localhost:8090).
2. Выберите шаблон и скопируйте его ID.
3. Передайте ID в `nexus_email_agent.py`.
