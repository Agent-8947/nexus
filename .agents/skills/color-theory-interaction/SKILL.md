# Interaction of Color: NEXUS Edition
**Source**: Josef Albers | **Version**: 2025.05

## 🎨 Core Principles of Perception

### 1. Color is Relative
A color has no absolute value. Its appearance changes completely depending on the colors surrounding it.
- **Rule**: Never choose a color in isolation. Always test it against the background and adjacent elements.

### 2. Vibrancy and Tension
Placing colors of similar value but different hues next to each other creates "vibrancy" or "visual vibration."
- **Rule**: Use this for high-energy sections, but avoid it for text legibility.

### 3. Transparency and Depth
Colors can be used to simulate transparency and overlap, creating a sense of depth without using 3D transforms.
- **Rule**: Use mid-tones to bridge two overlapping colors to create a "glass" effect.
