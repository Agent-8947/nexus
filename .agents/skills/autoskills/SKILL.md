# Skill: Autoskills [NEXUS Hardened]
Description: Автоматический менеджер навыков для AI-агентов. Синхронизирует проект со спецификациями и лучшими практиками коммьюнити.

## Когда использовать
- При инициализации нового проекта.
- После добавления новых технологий (React, GSAP, Supabase и т.д.).
- Для аудита текущего набора инструкций агента.

## Команды
- `npx autoskills`: Запустить сканирование и установку (интерактивно).
- `npx autoskills -y`: Автоматическая установка всех обнаруженных навыков.
- `npx autoskills --dry-run`: Просмотр списка навыков без установки.
- `npx autoskills --clear-cache`: Очистка кеша загруженных навыков.

## Интеграция с NEXUS
- Все навыки устанавливаются в `.agents/skills/`.
- Состояние фиксируется в `skills-lock.json`.
- Для обновления используйте воркфлоу `/skills`.

## Безопасность
- Все скачиваемые файлы проверяются по SHA-256.
- Используется только проверенный реестр `midudev/autoskills`.
