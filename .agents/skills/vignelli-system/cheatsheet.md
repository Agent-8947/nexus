# Cheatsheet: The Vignelli Canon

## 🖋 Typeface Selection
Only use these unless there is a critical brand requirement:
- **Helvetica** (Sans) — The default for clarity.
- **Bodoni** (Serif) — For elegance and contrast.
- **Garamond** — For long-form readability.
- **Century Expanded** — For structured information.
- **Caslon** — Alternative serif.

## 🎨 Color Palette
Vignelli preferred primary colors and extreme contrast:
- **Red**: #FF0000 (Vignelli Red)
- **Black**: #000000
- **White**: #FFFFFF
- **Gray**: Various shades for hierarchy.

## 📏 Grid Alignment
- **Margins**: Generous.
- **Gutters**: Consistent (e.g., 20px).
- **Alignment**: Flush left, Ragged right.
- **Tracking**: Tight but readable (never loose).

## 🚫 Anti-Patterns (The "Don'ts")
1. **Never** use "shadows" or "glows" on type.
2. **Never** stretch or distort fonts.
3. **Never** use decorative fonts (Comic Sans, Papyrus, etc.).
4. **Avoid** center-alignment for long text blocks.
5. **Avoid** using design as self-expression; it is a service.
