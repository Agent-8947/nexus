# Design Patterns: Vignelli System

## 🔳 The Modular Grid
**When to use**: Always. For every screen, document, or interface.
**How**: 
1. Divide the page into equal horizontal and vertical modules.
2. Define "Gutter" space between modules.
3. Align all text blocks, images, and UI elements to these modules.
**Trade-offs**: Requires strict discipline; may feel "rigid" initially, but provides ultimate consistency.

## 🔡 Typographic Hierarchy (The Scale Shift)
**When to use**: When needing to emphasize information.
**How**:
1. Stick to ONE typeface (e.g., Helvetica).
2. Shift scale dramatically (e.g., 12pt for body, 72pt for display).
3. Use only 2-3 weights (Light, Regular, Bold).
**Avoid**: Using more than 2 typefaces in a single composition.

## ↔️ Left-Aligned / Ragged Right
**When to use**: Standard text blocks.
**How**: Keep the left edge perfectly straight (aligned to grid) and let the right edge breathe (ragged).
**Why**: Ensures readability and prevents awkward hyphenation or spacing issues seen in justified text.

## 🌑 The Information White-out
**When to use**: High-end branding or posters.
**How**: Use excessive whitespace (up to 70% of the canvas) to force focus on a single, perfectly positioned element.
**Goal**: Intellectual elegance.
