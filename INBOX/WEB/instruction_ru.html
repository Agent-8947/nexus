Introduction - Флот AI-Агентов и Скилов - Полное описание — 25 агентов

«Каждый агент — специализированный эксперт со своей методологией»

AI-Orchestrated-NEXUS-v2 | 2026 - nexus-presentation-v2.vercel.app - Флот AI-агентов NEXUS OS

NEXUS OS управляется флотом специализированных AI-агентов. Каждый агент — это не просто инструмент, а полноценный эксперт со своей методологией, зоной ответственности и стандартами качества. Агенты делятся на два класса: системные (встроены в ядро) и скилы (подключаемые модули).

Всего агентов и скилов: 25 (4 системных + 21 скил). Агенты работают автономно или в составе многоагентных пайплайнов через Multi-Agent Orchestrator.

Системные агенты (ядро)

Эти агенты встроены в ядро NEXUS и обеспечивают базовые операции: оркестрацию, самовосстановление, генерацию документов и работу с базами данных.

Специализированные скилы

Подключаемые модули с узкой специализацией. Каждый скил имеет собственный SKILL.md с детальной методологией и инструкциями по применению.

Answering Engine

AI-поисковый движок с Deep Search Loop (поиск → верификация → синтез). Борется с галлюцинациями через принцип «Истина снаружи» — интегрирует SearXNG, Exa, Tavily.

OSINT Tactician

Методология разведки на основе Intelligence Cycle и принципов Hunchly. Планирует расследования по корпоративной разведке, поиску людей и маппингу инфраструктуры. Поддерживает Dark Web Recon.

Security Audit

AI-аудит безопасности на базе Ship Safe v5.0. Сканирует секреты, инъекции и уязвимости. Защищает AI-агентов от prompt injection. Содержит готовые сниппеты Rate Limiting, JWT, CORS.

Motion Design Expert

Премиальные веб-анимации и интерактивный motion. Специализируется на Three.js, GSAP, Framer Motion. Обеспечивает стабильный 60fps, работает с частицами, шейдерами и параллакс-эффектами.

Knowledge Synthesizer

Синтез знаний из нескольких источников без дублирования. Нормализует входные данные, разделяет подтвержденные факты от гипотез, строит решение-ориентированный обзор.

Domain Intel

Пассивная разведка доменов: поддомены, SSL-сертификаты, WHOIS, DNS-записи, доступность домена. Zero dependencies, работает на чистом Python stdlib без API-ключей.

Firecrawl

Официальный CLI-скил для веб-скрейпинга, поиска и браузерной автоматизации. Возвращает чистый Markdown, оптимизированный для LLM-контекста. Поддерживает bulk crawling и маппинг сайтов.

Frontend Orchestrator

Оркестрация frontend-разработки. Управляет маппингом роутов, состоянием компонентов и контрактами API. Фокус на React, Vite, Three.js с соблюдением design system.

Git-Native Agent

Фреймворк-агностичный стандарт Open-GitAgent для определения AI-агентов в Git. Управляет версионированием агентов, Segregation of Duties и enterprise compliance.

GitHub PR Workflow

Полный lifecycle Pull Request: создание ветки → коммиты → push → PR → мониторинг CI → merge. Использует gh CLI с fallback на git + curl.

JustDoIt

Основной движок исполнения задач v5.0. Реализует цикл Understand → Plan → Act → Verify. Исключает дрейф контекста и галлюцинации. Создает plans.md, status.md, test-plan.md.

Context Manager

Упаковка контекста для субагентов. Маппинг релевантной архитектуры, извлечение ограничений, компрессия в минимальный пакет с явным указанием неизвестных.

Multi-Agent Orchestrator

Планирование многоагентного выполнения с четким разделением ролей, зависимостями и интеграцией результатов. Максимизирует параллельный прогресс без потери контроля.

Nexus QA

QA Lead Mode v5.0. Автоматически тестирует веб-приложения через браузерную автоматизацию. Diff-Aware тестирование, проверка 404/500 и кликабельности. Генерирует qa_report.md с Health Score.

Nexus Vision (CEO Mode)

Режим «Партнера YC». Переформулирует задачи, оспаривает допущения, обеспечивает product-market fit до начала разработки. Результат — design_doc.md с Pain, Wedge и Engineering Constraints.

Legal Compliance Expert

Анализ правовых рисков и регуляторного соответствия. Маппинг юридического домена, разделение подтвержденных фактов от допущений, adversarial валидация нормального и аварийного пути.

UI/UX Designer

Создание implementation-ready UI-руководств с премиальной эстетикой (glassmorphism, micro-animations). Фокус на визуальной иерархии, ARIA, keyboard navigation и design system токенах.

arXiv Research

Поиск и получение академических статей через arXiv REST API. Без API-ключей. Интеграция с Semantic Scholar для цитат и связанных работ. Генерация BibTeX цитат.

Codebase Inspection

Анализ кодовой базы через pygount: подсчет LOC, разбивка по языкам, соотношение код/комментарии. Метрики репозитория для pre-refactor аудита.

MathLib Advisor

База знаний по математике и формальной логике на основе Lean 4 Mathlib. Поиск теорем, определений и лемм в крупнейшей библиотеке формализованной математики.

PowerShell UI Architect

Интерактивные инструменты и терминальные UI для Windows. TUI, WinForms/WPF интеграция, background jobs без заморозки интерфейса, safe execution привилегированных операций.

Итого агентов и скилов: 25 - MCP Neural Net — Коннекторы - Полное описание — 22 коннектора

«MCP-коннекторы — это руки и глаза NEXUS, связывающие AI с реальными системами»

AI-Orchestrated-NEXUS-v2 | 2026 - nexus-presentation-v2.vercel.app - MCP Neural Net — 22 внешних коннектора

MCP (Model Context Protocol) — это нейронная сеть NEXUS, дающая системе прямой доступ к внешним инструментам и сервисам. Без MCP AI видит только текст; с MCP он может читать файлы, делать коммиты, искать в интернете, запускать браузер и управлять базами данных.

Все MCP-серверы настроены в PROJECT/mcp_config.json и запускаются автоматически при старте Claude Desktop / VS Code Copilot. Pare-инструменты обеспечивают экономию токенов 40–70%.

Файловая система и данные

Коннекторы для работы с локальными файлами, репозиторием и базами данных.

filesystem

Прямой доступ к файловой системе проекта (чтение, запись, листинг директорий). Точка монтирования: PROJECT/

git

Нативная интеграция с Git-репозиторием: коммиты, диффы, история, ветки прямо из контекста AI.

memory

Персистентное Key-Value хранилище памяти через @modelcontextprotocol/server-memory. Сохраняет контекст между сессиями.

sqlite

Прямые запросы к локальной SQLite базе nexus_core.db. Используется для логирования команд и метрик API.

fetch

HTTP-клиент для получения веб-страниц и REST API данных. Базовый инструмент для сбора внешних данных.

brave-search

Веб-поиск через Brave Search API в реальном времени. Основной инструмент для получения актуальной информации из интернета.

Внешние сервисы и интеграции

Подключение к облачным сервисам, мониторингу, CMS и браузерной автоматизации.

sentry

Интеграция с Sentry для мониторинга ошибок. Получение staktrace, событий и performance-метрик прямо в контексте AI.

puppeteer

Браузерная автоматизация через Puppeteer: скриншоты, клики, навигация, рендеринг JS-страниц. Используется QA-агентом и motion-рекордером.

sequentialthinking

Инструмент структурированного последовательного мышления. Разбивает сложные задачи на атомарные шаги с явными промежуточными состояниями.

everart

AI-генерация изображений через EverArt. Используется Document Factory для создания визуальных активов в документах.

obsidian

Подключение к Obsidian Vault как к базе знаний. Чтение и запись заметок, маппинг связей между концептами проекта.

contentful

Headless CMS интеграция. Управление контентом, публикация записей и получение данных через Contentful API.

osp-marketing

Маркетинговые MCP-инструменты OSP. Генерация маркетингового контента, анализ целевой аудитории и стратегий.

ai-therapist

Когнитивный коннектор для анализа рабочих паттернов и устранения «токсичных» циклов разработки. Помогает в рефлексии и ретроспективах.

Pare-оптимизированные инструменты и графовая БД

Оптимизированные через Pare Tools версии Git/GitHub/Search/HTTP с токен-экономией, а также графовая база данных Neo4j и PostgreSQL.

pare-git

Оптимизированный Git через Pare Tools. Структурированный JSON-вывод вместо raw CLI. Экономия токенов 40–70% по сравнению с прямыми git-командами.

pare-github

Оптимизированный GitHub через Pare Tools. PR, Issues, Actions через структурированный API с минимальным токен-потреблением.

pare-search

Оптимизированный поиск через Pare Tools. Структурированные результаты поиска с токен-экономией и фильтрацией шума.

pare-python

Запуск Python-кода через Pare Tools с структурированным выводом. Безопасное выполнение скриптов с контролируемым окружением.

pare-process

Управление системными процессами через Pare Tools. Запуск, мониторинг и остановка процессов с JSON-ответами.

pare-http

HTTP-запросы через Pare Tools с структурированным выводом. REST API вызовы с автоматической сериализацией и обработкой ошибок.

neo4j

Граф-база данных Neo4j для хранения динамических связей между сущностями проекта. Адрес: bolt://localhost:7687, база nexus_graph_db.

postgres

Подключение к PostgreSQL через Supabase. Основная реляционная база данных проекта. Адрес: nexus_core (localhost:5432).

Итого MCP-коннекторов: 22 - 24 Slash-Команды (Воркфлоу) - Полное описание каждой команды

«Вся мощь NEXUS вызывается одной командой из терминала»

AI-Orchestrated-NEXUS-v2 | 2026 - nexus-presentation-v2.vercel.app - 24 Slash-команды NEXUS OS

Воркфлоу — это модульные команды, активирующие определенную цепочку действий NEXUS. Они вводятся прямо в чат IDE (Claude/Copilot) и запускают автоматизированные пайплайны: от форматирования кода до полного деплоя в production.

Воркфлоу хранятся в .agents/workflows/*.md. Команда /menu выводит полный список в любой момент. Большинство воркфлоу помечены // turbo-all — автономное выполнение без уточнений.
