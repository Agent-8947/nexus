"Each agent is a specialized expert with its own methodology"

AI-Orchestrated-NEXUS-v2 | 2026 - nexus-presentation-v2.vercel.app - NEXUS OS AI Agent Fleet

NEXUS OS is operated by a fleet of specialized AI agents. Each agent is not just a tool — it is a fully-fledged expert with its own methodology, area of responsibility, and quality standards. Agents are divided into two classes: core (built into the kernel) and skills (pluggable modules).

Total agents and skills: 25 (4 core + 21 skills). Agents operate autonomously or as part of multi-agent pipelines via the Multi-Agent Orchestrator.

Core agents (kernel)

These agents are built into the NEXUS kernel and provide fundamental operations: orchestration, self-healing, document generation, and database interaction.

Specialized skills

Pluggable modules with narrow specialization. Each skill has its own SKILL.md with detailed methodology and usage instructions.

Total agents and skills: 25 - MCP Neural Net — Connectors - Complete Description — 22 Connectors

"MCP connectors are NEXUS's hands and eyes, linking AI to real systems"

AI-Orchestrated-NEXUS-v2 | 2026 - nexus-presentation-v2.vercel.app - MCP Neural Net — 22 External Connectors

MCP (Model Context Protocol) is the neural network of NEXUS, giving the system direct access to external tools and services. Without MCP the AI only sees text; with MCP it can read files, make commits, search the web, run a browser, and manage databases.

All MCP servers are configured in PROJECT/mcp_config.json and start automatically on Claude Desktop / VS Code Copilot launch. Pare tools provide 40–70% token savings.

Connectors for working with local files, the repository, and databases.

Native Git repository integration: commits, diffs, history, and branches directly from AI context.

Total MCP connectors: 22 - 24 Slash Commands (Workflows) - Complete Description of Each Command

"The full power of NEXUS is invoked with a single terminal command"

AI-Orchestrated-NEXUS-v2 | 2026 - nexus-presentation-v2.vercel.app - 24 NEXUS OS Slash Commands

Workflows are modular commands that activate a specific chain of NEXUS actions. They are typed directly into the IDE chat (Claude/Copilot) and trigger automated pipelines — from code formatting to full production deployment.

Workflows are stored in .agents/workflows/*.md. The /menu command lists all available commands at any time. Most workflows are tagged // turbo-all — autonomous execution without follow-up questions.
