Introduction - Флот AI-Агентів і Скілів - Повний опис — 25 агентів

«Кожен агент — спеціалізований експерт зі своєю методологією»

AI-Orchestrated-NEXUS-v2 | 2026 - nexus-presentation-v2.vercel.app - Флот AI-агентів NEXUS OS

NEXUS OS управляється флотом спеціалізованих AI-агентів. Кожен агент — це не просто інструмент, а повноцінний експерт зі своєю методологією, зоною відповідальності та стандартами якості. Агенти поділяються на два класи: системні (вбудовані в ядро) і скіли (підключувані модулі).

Всього агентів і скілів: 25 (4 системних + 21 скіл). Агенти працюють автономно або у складі багатоагентних пайплайнів через Multi-Agent Orchestrator.

Системні агенти (ядро)

Ці агенти вбудовані в ядро NEXUS і забезпечують базові операції: оркестрацію, самовідновлення, генерацію документів і роботу з базами даних.

Спеціалізовані скіли

Підключувані модулі з вузькою спеціалізацією. Кожен скіл має власний SKILL.md із детальною методологією та інструкціями щодо застосування.

Answering Engine

AI-пошуковий рушій із Deep Search Loop (пошук → верифікація → синтез). Бореться з галюцинаціями через принцип «Істина назовні» — інтегрує SearXNG, Exa, Tavily.

OSINT Tactician

Методологія розвідки на основі Intelligence Cycle і принципів Hunchly. Планує розслідування корпоративної розвідки, пошуку людей і маппінгу інфраструктури. Підтримує Dark Web Recon.

Security Audit

AI-аудит безпеки на базі Ship Safe v5.0. Сканує секрети, ін'єкції та вразливості. Захищає AI-агентів від prompt injection. Містить готові сніппети Rate Limiting, JWT, CORS.

Motion Design Expert

Преміальні веб-анімації та інтерактивний motion. Спеціалізується на Three.js, GSAP, Framer Motion. Гарантує стабільні 60fps, працює з частинками, шейдерами та паралакс-ефектами.

Knowledge Synthesizer

Синтез знань із кількох джерел без дублювання. Нормалізує вхідні дані, розділяє підтверджені факти від гіпотез, будує рішення-орієнтований огляд.

Domain Intel

Пасивна розвідка доменів: субдомени, SSL-сертифікати, WHOIS, DNS-записи, доступність домену. Zero dependencies — чистий Python stdlib без API-ключів.

Firecrawl

Офіційний CLI-скіл для веб-скрейпінгу, пошуку та браузерної автоматизації. Повертає чистий Markdown, оптимізований для LLM-контексту. Підтримує bulk crawling та маппінг сайтів.

Frontend Orchestrator

Оркестрація frontend-розробки. Керує маппінгом роутів, станом компонентів і контрактами API. Фокус на React, Vite, Three.js зі збереженням design system.

Git-Native Agent

Фреймворк-агностичний стандарт Open-GitAgent для визначення AI-агентів у Git. Керує версіонуванням агентів, Segregation of Duties і enterprise compliance.

GitHub PR Workflow

Повний lifecycle Pull Request: створення гілки → коміти → push → PR → моніторинг CI → merge. Використовує gh CLI з fallback на git + curl.

JustDoIt

Основний рушій виконання задач v5.0. Реалізує цикл Understand → Plan → Act → Verify. Усуває дрейф контексту та галюцинації. Створює plans.md, status.md, test-plan.md.

Context Manager

Пакування контексту для субагентів. Маппінг релевантної архітектури, витягання обмежень, компресія в мінімальний пакет із явним зазначенням невідомих.

Multi-Agent Orchestrator

Планування багатоагентного виконання з чітким розподілом ролей, залежностями та інтеграцією результатів. Максимізує паралельний прогрес без втрати контролю.

Nexus QA

QA Lead Mode v5.0. Автоматично тестує веб-застосунки через браузерну автоматизацію. Diff-Aware тестування, перевірка 404/500 і клікабельності. Генерує qa_report.md з Health Score.

Nexus Vision (CEO Mode)

Режим «Партнера YC». Переформулює задачі, оскаржує допущення, забезпечує product-market fit до початку розробки. Результат — design_doc.md із Pain, Wedge, Engineering Constraints.

Legal Compliance Expert

Аналіз правових ризиків і регуляторної відповідності. Маппінг юридичного домену, розділення підтверджених фактів від допущень, adversarial валідація.

UI/UX Designer

Implementation-ready UI-керівництва з преміальною естетикою (glassmorphism, micro-animations). Фокус на візуальній ієрархії, ARIA, keyboard navigation і design system токенах.

arXiv Research

Пошук і отримання академічних статей через arXiv REST API. Без API-ключів. Інтеграція з Semantic Scholar для цитат. Генерація BibTeX цитат.

Codebase Inspection

Аналіз кодової бази через pygount: підрахунок LOC, розбивка по мовах, співвідношення код/коментарі. Метрики репозиторію для pre-refactor аудиту.

MathLib Advisor

База знань з математики та формальної логіки на базі Lean 4 Mathlib. Пошук теорем, визначень і лем у найбільшій бібліотеці формалізованої математики.

PowerShell UI Architect

Інтерактивні інструменти та термінальні UI для Windows. TUI, WinForms/WPF інтеграція, фонові задачі без заморозки інтерфейсу, безпечне виконання привілейованих операцій.

Всього агентів і скілів: 25 - MCP Neural Net — Конектори - Повний опис — 22 конектори

«MCP-конектори — це руки та очі NEXUS, що пов'язують AI із реальними системами»

AI-Orchestrated-NEXUS-v2 | 2026 - nexus-presentation-v2.vercel.app - MCP Neural Net — 22 зовнішні конектори

MCP (Model Context Protocol) — це нейронна мережа NEXUS, що надає системі прямий доступ до зовнішніх інструментів і сервісів. Без MCP AI бачить лише текст; із MCP він може читати файли, робити коміти, шукати в інтернеті, запускати браузер і керувати базами даних.

Всі MCP-сервери налаштовані в PROJECT/mcp_config.json і запускаються автоматично при старті Claude Desktop / VS Code Copilot. Pare-інструменти забезпечують економію токенів 40–70%.

Файлова система та дані

Конектори для роботи з локальними файлами, репозиторієм і базами даних.

filesystem

Прямий доступ до файлової системи проєкту (читання, запис, лістинг директорій). Точка монтування: PROJECT/

git

Нативна інтеграція з Git-репозиторієм: коміти, діффи, історія, гілки прямо з контексту AI.

memory

Персистентне Key-Value сховище пам'яті через @modelcontextprotocol/server-memory. Зберігає контекст між сесіями.

sqlite

Прямі запити до локальної SQLite бази nexus_core.db. Використовується для логування команд і метрик API.

fetch

HTTP-клієнт для отримання веб-сторінок і REST API даних. Базовий інструмент для збору зовнішніх даних.

brave-search

Веб-пошук через Brave Search API в реальному часі. Основний інструмент для отримання актуальної інформації з інтернету.

Зовнішні сервіси та інтеграції

Підключення до хмарних сервісів, моніторингу, CMS і браузерної автоматизації.

sentry

Інтеграція з Sentry для моніторингу помилок. Отримання stack trace, подій і performance-метрик прямо в контексті AI.

puppeteer

Браузерна автоматизація через Puppeteer: скриншоти, кліки, навігація, рендеринг JS-сторінок. Використовується QA-агентом і motion-рекордером.

sequentialthinking

Інструмент структурованого послідовного мислення. Розбиває складні задачі на атомарні кроки з явними проміжними станами.

everart

AI-генерація зображень через EverArt. Використовується Document Factory для створення візуальних активів у документах.

obsidian

Підключення до Obsidian Vault як до бази знань. Читання і запис нотаток, маппінг зв'язків між концептами проєкту.

contentful

Headless CMS інтеграція. Управління контентом, публікація записів і отримання даних через Contentful API.

osp-marketing

Маркетингові MCP-інструменти OSP. Генерація маркетингового контенту, аналіз цільової аудиторії та стратегій.

ai-therapist

Когнітивний конектор для аналізу робочих патернів і усунення «токсичних» циклів розробки. Допомагає в рефлексії та ретроспективах.

Pare-оптимізовані інструменти та граф-БД

Оптимізовані через Pare Tools версії Git/GitHub/Search/HTTP з економією токенів, а також граф-база Neo4j і PostgreSQL.

pare-git

Оптимізований Git через Pare Tools. Структурований JSON-вивід замість raw CLI. Економія токенів 40–70% порівняно з прямими git-командами.

pare-github

Оптимізований GitHub через Pare Tools. PR, Issues, Actions через структурований API з мінімальним споживанням токенів.

pare-search

Оптимізований пошук через Pare Tools. Структуровані результати пошуку з економією токенів і фільтрацією шуму.

pare-python

Запуск Python-коду через Pare Tools зі структурованим виводом. Безпечне виконання скриптів у контрольованому середовищі.

pare-process

Управління системними процесами через Pare Tools. Запуск, моніторинг і зупинка процесів із JSON-відповідями.

pare-http

HTTP-запити через Pare Tools зі структурованим виводом. REST API виклики з автоматичною серіалізацією та обробкою помилок.

neo4j

Граф-база даних Neo4j для зберігання динамічних зв'язків між сутностями проєкту. Адреса: bolt://localhost:7687, база nexus_graph_db.

postgres

Підключення до PostgreSQL через Supabase. Основна реляційна база даних проєкту. Адреса: nexus_core (localhost:5432).

Всього MCP-конекторів: 22 - 24 Slash-Команди (Воркфлоу) - Повний опис кожної команди

«Вся потужність NEXUS викликається однією командою з термінала»

AI-Orchestrated-NEXUS-v2 | 2026 - nexus-presentation-v2.vercel.app - 24 Slash-команди NEXUS OS

Воркфлоу — це модульні команди, що активують певний ланцюжок дій NEXUS. Вони вводяться прямо в чат IDE (Claude/Copilot) і запускають автоматизовані пайплайни: від форматування коду до повного деплою в production.

Воркфлоу зберігаються в .agents/workflows/*.md. Команда /menu виводить повний список у будь-який момент. Більшість воркфлоу позначені // turbo-all — автономне виконання без уточнень.
