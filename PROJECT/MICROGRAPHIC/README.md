# MICROGRAPHIC

Проект исследования генеративного искусства, алгоритмической музыки и виджеинга в реальном времени.

## Структура директорий

- **0001**: Оригинальный модульный концепт. Статичная сетка с интеграцией SoundCloud (воспроизведение без анализа частот).
- **0002**: Эксперимент "Cyberpunk Stripes". Агрессивные неоновые полосы, аддитивное наложение, прямая синхронизация с процедурным битом.
- **0003**: Эксперимент "Sensual Silk". Психоделический фрактальный туннель, нейросетевые связи на кривых Безье, "дышащий" пад и пульс сердцебиения.
- **0004**: Зафиксированная копия стабильной версии `0002` (Rhythm Sync).

## Референсный стек для дальнейшего расширения

Для перехода от чистого Canvas к профессиональному VJ-инструментарию рекомендуется использовать:
1. **Hydra** (`hydra-synth`): Можно подключить прямо в HTML через CDN для генерации сложных видеоэффектов кодом.
2. **p5.js**: Для более простой работы с геометрией и аудиоанализом.
3. **VEDA / ISF**: При переходе на тяжелую графику на базе чистых GLSL-шейдеров.
