# Agent-V [MOTION-GENESIS] Laws

1. **Stack Purity**: Используется только Vanilla HTML5, CSS3 (Tailwind) и GSAP 3.
2. **Kinetic Consistency**: Любой элемент должен иметь входную/выходную анимацию (Entrance/Exit).
3. **Anchor First**: Навигация строится на 3D-камере (Camera Rig), где якоря — это координаты в 3D пространстве.
4. **Visual Loyalty**: Цветовая схема и типографика должны строго соответствовать анализу референса.
5. **Zero Stub**: Генерируемый код должен быть self-contained (всё в одном файле или с CDN ссылками).
