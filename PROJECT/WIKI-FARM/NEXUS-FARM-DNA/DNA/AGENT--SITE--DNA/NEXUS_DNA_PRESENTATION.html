Core Principle · Жесткий контракт

Code over Guessing.

Мы отказались от LLM-Vision для извлечения базовых стилей. Зрение AI галлюцинирует шрифты. DOM — никогда.

Скрипт `nexus_visual_analyzer.py` использует инъекцию JS для извлечения точных CSS-переменных, `letter-spacing`, `font-weight`. AI включается только на этапе стратегии (`DNA_MOTION_ARCHITECT`), когда детерминированный `dna.json` уже собран.

"Точность пикселей не должна зависеть от температуры промпта."
— NEXUS Philosophy
{ "brand_name": "Solara", "typography": { "headings": { "fontFamily": "Instrument Serif", "letterSpacing": "-0.04em" } }, "colors": { "accent": "hsl(14.7, 95%, 52.9%)" } }
