# 🧬 CARIDDI: Web Extraction DNA

Высокоскоростной краулер для анализа доменов. Источник генов для **автоматизированного поиска данных и уязвимостей в вебе**.

## 🕹 Генетический Профиль
- **Deep URL Discovery**: Алгоритмы рекурсивного поиска всех доступных ссылок и эндпоинтов цели.
- **Multi-Pattern Secret Hunter**: Система регулярных выражений для детекции чувствительных данных (ключи, токены) в реальном времени.

## 🛠 Применение в NEXUS
- **Target Surface Mapping**: Составление карты цифрового следа цели для разведывательных агентов.
- **Automated Credential Discovery**: Пассивный сбор учетных данных для расширения прав доступа в миссиях.
