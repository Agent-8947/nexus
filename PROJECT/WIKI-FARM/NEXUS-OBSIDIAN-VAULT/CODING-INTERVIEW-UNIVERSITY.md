# CODING-INTERVIEW-UNIVERSITY — The Ultimate CS Degree Study Plan

## Описание
**Coding Interview University** — это легендарный учебный план по компьютерным наукам (Computer Science) для тех, кто хочет стать **Senior Software Engineer** в топовых компаниях (Amazon, Google, Microsoft) без формального диплома. Это путь длиною в тысячи часов чтения, практики и написания кода. Репозиторий охватывает всё: от структур данных до архитектуры систем.

## Что внутри (Учебный План)
1. **Algorithmic Complexity**— Big O notation, O(1), O(n), O(log n).
2. **Data Structures**— Linked Lists, Stacks, Queues, Hash Tables, Trees (BST, Red-Black, AVL), Heaps.
3. **Algorithms**— Sorting (Quick, Merge), Graph algorithms (BFS, DFS, Dijkstra), Bit manipulation.
4. **Operating Systems**— Процессы, Потоки (Thread), Прерывания, Виртуальная память.
5. **System Design**— Шардирование, Репликация, Кеширование, CAP-теорема.
6. **Object-Oriented Programming**— SOLID, Design Patterns.

## Почему это Killer-App для ИИ
- **Knowledge Hierarchy**— Список тем — это идеальный онтологический граф знаний для вашего ИИ-агента.
- **Reference List**— Ссылки на лучшие статьи и видео по каждой теме (напр. MIT OpenCourseWare).
- **Quality Standard**— Это эталон того, что должен знать "сильный" инженер.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Базовый Интеллектуальный Стык (CS Fundamentals). Если агент NEXUS пишет архитектурное решение, он должен следовать этим канонам.
- **Интеграция:** Можно использовать темы из списка для создания тестов (Quiz) для проверки когнитивных способностей новых локальных моделей.
- **Ключевое:** Охватывает темы масштабирования, критические для NEXUS Orchestrator.

## Темы "С чего начать"
- **Memory Management**— как данные лежат в RAM.
- **Recursion vs Iteration**— когда что использовать.
- **Bitwise Operations**— как считать "битами" (быстрее всего).
