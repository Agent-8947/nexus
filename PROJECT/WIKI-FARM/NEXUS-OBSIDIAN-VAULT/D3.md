# D3 — Data-Driven Documents (v7+)

## Описание
**D3.js** — это легендарная JavaScript-библиотека для манипулирования документами на основе данных. В отличие от простых библиотек графиков, D3 не дает вам "готовых" чартов, а дает низкоуровневые инструменты для связки данных с DOM-элементами (SVG, Canvas, HTML). Это позволяет создавать абсолютно любую визуализацию — от простых линий до сложнейших графов связей и 3D-проекций.

## Технический Стек
| Компонент | Технология |
|-----------|------------|
| Rendering | Dynamic SVG / Canvas / HTML5 |
| Concept | Data-binding (Join, Enter, Update, Exit) |
| Layouts | Force, Cluster, Tree, Pie, Zoom |
| Projections | Geo-projections (Maps) |
| Transitions | Native Animations / Chaining |

## Почему это Killer-App
1. **Total Control**— вы решаете, как будет выглядеть каждый пиксель в зависимости от значения данных.
2. **Scalability**— одинаково хорошо работает с 10 и с 10 000 объектов (через Canvas/Web Search).
3. **Graph Layouts**— один из лучших в мире движков "силовых графов" (Force-directed graphs), что идеально для визуализации связей.
4. **Geo Data**— мощнейший инструментарий для работы с географическими картами и проекциями.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Визуализация Сложных Связей (Entity Relationship Graph). Идеально для графа знаний вашего Obsidian Vault — вы можете построить свою карту связей репозиториев на D3.
- **Интеграция:** Модуль NEXUS Dashboard — отрисовка состояния сети, межагентской коммуникации и OSINT-карт целей.
- **Ключевое:** Использование асинхронной загрузки данных (`d3.csv`, `d3.json`).

## Пример: Привязка данных (Data Join)
```javascript
import * as d3 from "d3";

// Связываем массив нейронов с кругами в SVG
d3.select("svg")
  .selectAll("circle")
  .data(nexus_neurons) // Массив объектов [{}, {}, ...]
  .enter()
  .append("circle")
  .attr("cx", d => d.x_coord)
  .attr("cy", d => d.y_coord)
  .attr("r", 5)
  .style("fill", "steelblue");
```
