# 2023-CS-STUDY — Глубокая Подготовка к CS Интервью (2023-2025)

## Описание
Интенсивный учебный репозиторий, созданный корейским сообществом разработчиков для подготовки к техническим интервью в топ-тех компании. Охватывает фундаментальные основы Computer Science: структуры данных, алгоритмы, операционные системы, сети и базы данных, а также прикладной стек (Java, Spring, JPA). Особенность: наличие раздела "Expected Questions" с реальными вопросами из практики интервью.

## Основные Разделы
1. **자료구조 & 알고리즘** — Теория графов, деревья, типичные алгоритмические задачи.
2. **운영체제 (OS)** — Процессы vs Потоки, управление памятью, планировщики.
3. **네트워크** — Стек TCP/IP, HTTP/HTTPS, DNS, Load Balancing.
4. **데이터베이스** — Индексы, транзакции (ACID), JOIN, NoSQL.
5. **Stack Specific** — Глубокий Java (JVM, GC), Spring Framework и JPA/Hibernate.
6. **Expected Questions** — Списки вопросов для самопроверки по каждой категории.

## Почему это Killer-App
- **Interview-Driven Learning** — фокус на том, что реально спрашивают, а не на абстрактной теории.
- **Deep Explanations** — темы разобраны с учетом архитектурных нюансов (например, почему JPA лучше JDBC в конкретных кейсах).
- **Curated Wiki** — структурированные майнд-карты и ссылки на дополнительные материалы.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Interview Agent Training — база знаний для NEXUS-QA и HR-агентов.
- **Интеграция:** Раздел `Expected questions` может быть использован для Adversarial-тестирования знаний других агентов.
- **Ключевое:** Использование корейского опыта (высокая конкуренция) дает более жесткий стандарт проверки знаний.

## Топ-3 примера (из Expected Questions)
- *OS:* "В чем разница между процессом и потоком в контексте переключения контекста?"
- *Network:* "Опишите процесс 3-way handshake в TCP."
- *Spring:* "Расскажите про жизненный цикл бина (Bean Life Cycle) в Spring IoC контейнере."
