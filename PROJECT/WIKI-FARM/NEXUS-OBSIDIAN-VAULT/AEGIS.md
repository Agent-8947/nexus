# AEGIS AUTHENTICATOR — Защищенное Управление Двухфакторной Аутентификацией

## Описание
Бесплатное, безопасное приложение с открытым исходным кодом для Android, предназначенное для управления 2FA (двухфакторной аутентификацией). Фокусируется на безопасности хранилища (vault), которое зашифровано по стандарту AES-256-GCM. Поддерживает алгоритмы HOTP и TOTP, обеспечивая совместимость с тысячами сервисов (Google, Microsoft, GitHub и др.).

## Основные Разделы
1. **Encrypted Vault** — защита данных через пароль (scrypt) или биометрию (Android Keystore).
2. **Import/Export Utility** — миграция из Google Authenticator, Authy, Microsoft Authenticator и др.
3. **Automatic Backups** — автоматическое резервное копирование зашифрованного хранилища.
4. **UI Customization** — иконки, группы, темы (Light, Dark, AMOLED).
5. **Security Hardening** — предотвращение захвата экрана, "Tap to reveal" (скрытие кодов до нажатия).

## Почему это Killer-App
- **True Privacy** — в отличие от облачных сервисов, данные хранятся только у пользователя.
- **Audit-Ready** — открытый код и детально описанный формат хранилища позволяют провести независимую проверку безопасности.
- **Superior UX** — мощный поиск, группы и "умные" иконки делают работу с сотнями кодов удобной.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Identity Guardian — модуль для NEXUS-агентов, отвечающих за безопасный доступ к API-ключам и внешним аккаунтам.
- **Интеграция:** Формат хранилища (vault format) может быть использован NEXUS для разработки внутреннего стандарта хранения "секретов" агентов.
- **Ключевое:** Использование `scrypt` для деривации ключей — золотой стандарт, который должен быть внедрен в NEXUS Security DNA.

## Как это работает (Security focus)
1. Данные шифруются AES-256-GCM.
2. Мастер-пароль проходит через scrypt (высокая стоимость перебора).
3. При использовании биометрии ключ хранится в Secure Hardware (Android Keystore).
