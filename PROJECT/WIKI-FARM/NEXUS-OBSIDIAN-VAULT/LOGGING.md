# LOGGING — The Black Box of NEXUS Intelligence (System Observability)

## Описание
**Logging** — это фундамент прозрачности и надежности любой сложной системы. Это "Черный ящик", который записывает каждое решение агентов, каждый сетевой запрос [[IP-RECON]] и каждый ответ ИИ [[LANGCHAIN]]. В современной архитектуре логирование — это не просто запись текста в файл, а создание структурированных JSON-записей, которые мгновенно индексируются в [[ELASTICSEARCH]] и визуализируются в [[KIBANA]]. Это позволяет восстановить картину любого инцидента за доли секунды.

## Технический Стек (Observability Stack)

| **OpenTelemetry** | Universal | Глобальный стандарт трассировки запросов между серверами |

## Почему это Killer-App
1. **Root Cause Analysis**— Если система NEXUS выдала ошибку "Данные не найдены", через логи вы увидите: "Агент А обратился к БД Б с тайм-аутом 5с".
2. **Structural Search**— Вы можете искать не по словам, а по полям: напр. "Покажи все логи с уровнем 'HACK_ATTACK' от IP 1.2.3.4 за последние 15 минут".
3. **Contextual Metadata**— Каждая строка лога несет в себе контекст: ID пользователя, ID задачи, количество свободной памяти и версию кода.
4. **Performance Monitoring**— Логи позволяют видеть время выполнения каждой функции, помогая находить "бутылочные горлышки" без профилировщиков.
5. **Security Auditing**— Неизменяемые логи действий (Audit logs) — это юридическое доказательство того, что и когда сделала ваша система.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Тотальная Прозрачность Когнитивных Процессов (Total Cognitive Transparency). Запись "мыслей" ИИ перед выдачей ответа.
- **Интеграция:** Модуль NEXUS Scribe — автоматическая трансляция всех локальных логов в облачную систему [[ELASTICSEARCH]] для глобального анализа.
- [[EVENT]] -> [[LOGGER]] -> [[STDOUT/STORAGE]] -> [[ELASTICSEARCH]] -> [[KIBANA]].

## Пример кода (Python / Structlog)
```python
import structlog

# 1. Настройка "Умного" логгера
logger = structlog.get_logger()

# 2. Логирование с метаданными (JSON-ready)
# ИИ-агенты NEXUS обожают такой формат
logger.info("nexus_recon_start", 
            target="1.2.3.4", 
            tool="nmap", 
            agent_id="A-99", 
            priority="high")

# Результат (в файле/консоли):
# {"event": "nexus_recon_start", "target": "1.2.3.4", "agent_id": "A-99", "level": "info", "timestamp": "2026-04-07T..."}
```
