# GBDT — Gradient Boosting Decision Trees (The Table King)

## Описание
**GBDT (Gradient Boosting Decision Trees)** — это не одна библиотека, а целое семейство алгоритмов машинного обучения (XGBoost, LightGBM, CatBoost), которые на сегодняшний день являются **абсолютными королями** в работе с **табличными данными**. В отличие от "модных" нейросетей (Deep Learning), GBDT показывают на порядок лучшие результаты на классических задачах: предсказание оттока клиентов, ранжирование поиска, оценка кредитных рисков и анализ временных рядов.

## Основные Представители
| Библиотека | Разработчик | Сильная сторона |
|------------|-------------|-----------------|
| **XGBoost** | DMLC (Academic) | Классика, высокая точность, поддержка GPU |
| **LightGBM**| Microsoft | Сверхвысокая скорость, работа с огромными данными |
| **CatBoost** | Yandex | Лучшая работа с категориями (текстом) без пре-процессинга |

## Почему это Killer-App
1. **Best for Tabular**— Если ваши данные — это числа, даты и категории в таблице (напр. логи из [[ELASTICSEARCH]]), GBDT победит любую нейросеть.
2. **Explainability**— В отличие от "черного ящика" нейросети, здесь можно четко увидеть, какие именно факторы (Feature Importance) повлияли на результат.
3. **Overfitting Control**— Встроенные механизмы регуляризации (L1, L2) не дают модели "зазубрить" данные.
4. **GPU Acceleration**— Все три библиотеки поддерживают мгновенное обучение на видеокартах.
5. **Robustness**— Спокойно относятся к пропускам в данных и не требуют нормализации (масштабирования) чисел.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Предиктивная Аналитика Событий (Predictive Event Analysis). Предсказание будущих нагрузок на вашу WIKI-ферму или вероятности успешного хака.
- **Интеграция:** Модуль NEXUS Predictor — автоматическая оценка "качества" и "интересности" новых репозиториев на базе 100+ параметров.
- [[DATAFRAME]] -> [[GBDT]] -> [[FORECAST]] аналитика.

## Пример кода (Python / XGBoost)
```python
import xgboost as xgb
from sklearn.model_selection import train_test_split

# 1. Загружаем данные о сканированиях
# X - фичи (порт, страна, время), y - цель (был ли взлом)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 2. Обучаем "бустинг"
model = xgb.XGBClassifier(n_estimators=100, max_depth=5, learning_rate=0.1)
model.fit(X_train, y_train)

# 3. Узнаем, что самое важное!
print(model.feature_importances_)
```
