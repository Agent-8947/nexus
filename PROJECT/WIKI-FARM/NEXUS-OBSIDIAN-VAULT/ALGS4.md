# ALGS4 — Алгоритмы, 4-е издание (Р. Седжвик, К. Уэйн)

## Описание
Официальный репозиторий с исходным кодом на Java для фундаментального учебника «Алгоритмы, 4-е издание». Проект содержит реализации «50 алгоритмов, которые должен знать каждый программист». Код оптимизирован для ясности, переносимости и эффективности, являясь золотым стандартом академической реализации структур данных и алгоритмов.

## Основные Разделы
1. **Fundamentals** — базовые структуры (стеки, очереди, сумки), анализ алгоритмов.
2. **Sorting** — быстрая сортировка, слиянием, кучей, элементарные сортировки.
3. **Searching** — бинарные деревья поиска (BST), красно-черные деревья, хеш-таблицы.
4. **Graphs** — поиск в ширину/глубину, алгоритмы Дейкстры, Прима, Краскала, потоки в сетях.
5. **Strings** — сортировка строк, префиксные деревья (Tries), сжатие данных.

## Почему это Killer-App
- **Academic Excellence** — проверенные и выверенные реализации от ведущих экспертов Принстонского университета.
- **Elegant Code** — акцент на элегантности и простоте изложения ключевых идей.
- **Library Support** — возможность использования в виде JAR-файла (`algs4.jar`) для учебных и исследовательских проектов.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Fundamental Logic Library — эталонные реализации для проверки корректности синтезированного NEXUS-кода.
- **Интеграция:** Использование JAR-библиотеки ALGS4 в качестве зависимости для Java-агентов NEXUS.
- **Ключевое:** Подход к организации пакета `edu.princeton.cs.algs4` как пример строгого структурирования библиотечных функций.

## Ключевые алгоритмы (Benchmarks)
- **Red-Black BSTs:** Самобалансирующиеся деревья для эффективного поиска.
- **Dijkstra SP:** Кратчайшие пути в графах.
- **Kruskal's MST:** Минимальные остовные деревья.
