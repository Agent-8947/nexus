# 🧬 CONTAINERSSH: Isolated Terminal DNA

SSH-сервер, который превращает каждое подключение в изолированный контейнер. Источник генов для **безопасного удаленного доступа и создания одноразовых сред**.

## 🕹 Генетический Профиль
- **Multi-backend Support**: Способность запускать сессии в Docker, Kubernetes или через кастомные SSH-прокси.
- **Audit Logging**: Детализированная запись всех действий пользователя внутри сессии с выгрузкой в S3.

## 🛠 Применение в NEXUS
- **Agent Sandbox Shell**: Предоставление агентам-исследователям безопасной командной строки для запуска потенциально опасного кода.
- **Dynamic Lab Environments**: Автоматическое развертывание учебных или тестовых стендов по требованию.
