# AIRSLAM — Сверхэффективная и Устойчивая к Освещению Visual SLAM-Система

## Описание
Передовая система визуальной одновременной локализации и картографирования (Visual SLAM), специально спроектированная для надежной работы в экстремальных условиях освещения. AirSLAM использует гибридный подход: Deep Learning (CNN) для детекции ключевых точек и структурных линий, совместно с традиционной оптимизацией бэкенда. Система оптимизирована для работы на встраиваемых платформах (NVIDIA Jetson) и достигает впечатляющей частоты кадров.

## Основные Разделы
1. **PLNet (Point-Line Network)** — обучаемая нейросеть для совместного извлечения точек и линий.
2. **Dual-Mode (V-SLAM / VI-SLAM)** — поддержка работы как только по камере, так и с инерциальным модулем (IMU).
3. **TensorRT Acceleration** — глубокая оптимизация инференса для GPU с поддержкой частоты до 73 Гц.
4. **Relocalization Pipeline** — легковесная система перелокализации по ранее построенной карте.
5. **Structure Graph** — использование геометрических связей между линиями и точками для повышения точности.

## Почему это Killer-App
- **Illumination Robustness** — стабильная работа там, где классические ORB-SLAM3 или VINS-Mono терпят неудачу.
- **Efficiency** — работа на частоте 40 Гц на встраиваемых платформах (Jetson) и 73 Гц на ПК.
- **High-Fidelity Mapping** — построение структурных карт с использованием линий, что дает более понятную геометрию для навигации.
- **Scientific Recognition** — принят в престижный журнал IEEE Transactions on Robotics (TRO), 2025.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Spatial Guardian — модуль "пространственного зрения" для NEXUS-агентов, отвечающих за навигацию дронов или роботов.
- **Интеграция:** Использование PLNet для OSINT-задач (анализ видео с камер наблюдения в плохом качестве).
- **Ключевое:** Технология `AirSLAM Map Refinement` позволяет NEXUS-агентам автономно улучшать качество цифровых двойников (Digital Twins) окружения.

## Технологический стек
- **Core:** C++, ROS Noetic.
- **Optimization:** Ceres Solver, G2O.
- **Inference:** CUDA, TensorRT 8.6+.
- **Vision:** OpenCV, Eigen 3.
