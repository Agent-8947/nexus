# ALGODS — Коллекция Алгоритмов, Структур Данных и Решений Задач

## Описание
Всеобъемлющий репозиторий, содержащий реализации фундаментальных алгоритмов и структур данных на языке Java. Проект включает в себя более 300 решений классических алгоритмических проблем, разбитых по уровням сложности (Easy, Medium, Hard), и служит практическим пособием для подготовки к техническим интервью в топ-тех компании.

## Основные Разделы
1. **Data Structures** — реализации Linked Lists, Binary Trees, AVL Trees, Tries, Stacks, Queues и LRU Cache.
2. **Algorithms** — сортировка (MergeSort, QuickSort), поиск (Binary Search), графы (BFS, DFS, Dijkstra, A*, MST).
3. **Dynamic Programming** — задачи на Knapsack, Coin Change, Subset Sum и Fibonacci.
4. **String Operations** — Rabin Karp, KMP, работа с палиндромами и анаграммами.
5. **Math** — Sieve of Eratosthenes, Fermat's primality test, Reverse Polish Notation.

## Почему это Killer-App
- **Pure Java Implementation** — четкий и структурированный код без лишних зависимостей.
- **Complexity Grading** — разделение задач по уровням помогает выстраивать поэтапное обучение.
- **Graph Heavy** — глубокая проработка алгоритмов на графах (Topological Sorting, Bridge Detection).
- **Interview Focused** — подборка задач, максимально приближенная к реальным вопросам с LeetCode и HackerRank.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Algorithmic Blueprint — NEXUS может использовать эти Java-реализации как эталон при генерации кода для корпоративных систем.
- **Интеграция:** Использование алгоритма `A* Heuristic Path Finding` для планировщиков миссий NEXUS-агентов.
- **Ключевое:** Структура `Trie` (префиксное дерево) из этого репозитория — идеальный паттерн для организации быстрого поиска по тегам в Obsidian Vault.

## Топ алгоритмов из коллекции
- **Dijkstra:** Кратчайший путь в графе.
- **Knapsack 0/1:** Классическая задача динамического программирования.
- **LRU Cache:** Паттерн управления памятью.
