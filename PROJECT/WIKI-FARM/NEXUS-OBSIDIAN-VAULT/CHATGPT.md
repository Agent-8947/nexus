# CHATGPT — Awesome Prompts & Hacks Master List

## Описание
**Awesome ChatGPT Prompts** — это самый большой в мире список **мастер-промптов (Prompts)** для извлечения максимальной пользы из ChatGPT, Claude, Gemini и других LLM. Список превращает "просто чат" в мощнейший инструмент: от симулятора Linux-терминала до эксперта в судебном анализе.

## Категории Промптов
1. **Developer Roles**— "Действуй как Full-stack разработчик", "Действуй как Code Auditor".
2. **System Simulation**— "Действуй как bash-терминал", "Действуй как Python REPL", "Действуй как браузер".
3. **Legal & Business**— "Действуй как юрист", "Действуй как аналитик угроз".
4. **Writing & Translation**— "Действуй как переводчик с сохранением стиля", "Действуй как редактор".
5. **Logic & Math**— пошаговые (step-by-step) рассуждения (CoT).

## Архитектурная Ценность для NEXUS
- **Паттерн:** Инженерия Намерений (Intent Engineering). Это база для `system_message` ваших автономных агентов.
- **Интеграция:** Модуль NEXUS Agent Core — автоматический выбор промпта в зависимости от роли агента (Разведчик, Архитектор, Юрист).
- **Ключевое:** Использование мета-промптов (промпты, которые пишут промпты) для адаптации ИИ к новым задачам.

## Топ-3 Примера ролей (Промпт)
```markdown
# 1. Симулятор терминала Linux
"Я хочу, чтобы вы выступили в роли терминала Linux. Я буду вводить команды, а вы будете отвечать тем, что должен показывать терминал. Я хочу, чтобы вы отвечали только выводом терминала внутри одного уникального блока кода и больше ничего."

# 2. Роль Архитектора NEXUS (Кастомный)
"Действуй как системный архитектор ИИ с фокусом на безопасность и отказоустойчивость. Твоя задача — анализировать 172 репозитория и создавать взаимосвязанную базу знаний в формате Obsidian..."

# 3. Code Auditor
"Действуй как Senior Security Auditor. Найди уязвимости в следующем коде, укажи их тип по классификации OWASP и предложи патч."
```
