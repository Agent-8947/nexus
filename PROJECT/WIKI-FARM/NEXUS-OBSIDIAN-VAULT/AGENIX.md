# AGENIX — Управление Секретами в NixOS через age-шифрование

## Описание
Легковесная библиотека для Nix, предназначенная для безопасного управления секретами (пароли, токены) с использованием SSH-ключей. Решает проблему "секретов в Nix-store", где все файлы по умолчанию доступны для чтения всем пользователям. Секреты шифруются утилитой `age` с использованием публичных SSH-ключей систем и пользователей, и автоматически расшифровываются при активации системы.

## Основные Разделы
1. **agenix CLI** — инструмент для редактирования и перешифрования (.age) файлов.
2. **NixOS Module** — интеграция в процесс сборки системы для автоматического монтирования секретов в `/run/agenix/`.
3. **Home-Manager Module** — поддержка пользовательских секретов в Home-Manager.
4. **Rekeying Engine** — механизм массового перешифрования секретов при изменении списка ключей доступа.

## Почему это Killer-App
- **No GPG required** — использует существующую SSH-инфраструктуру, избавляя от боли настройки GPG.
- **Git-friendly** — зашифрованные файлы можно безопасно хранить в публичных репозиториях.
- **Minimal Codebase** — легкость аудита кода (критично для безопасности).
- **Nix Native** — глубокая интеграция в экосистему NixOS/Flakes.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Infra Secret Engine — основной стандарт для NEXUS-агентов, управляющих облачной или локальной инфраструктурой.
- **Интеграция:** Автоматическое создание `secrets.nix` на основе NEXUS Node DNA.
- **Ключевое:** Принцип "Zero-Knowledge on host" — секреты расшифровываются только в памяти/runtime, не попадая в Nix-store в открытом виде.

## Рабочий процесс (NEXUS focus)
1. Создание `secrets.nix` (определение ролей: кто может читать секрет).
2. Выполнение `agenix -e secret.age` (редактирование в $EDITOR).
3. Добавление пути в `age.secrets."config".file` в конфигурации NixOS.
4. Потребление секрета через `config.age.secrets."config".path`.
