# AB3DMOT — Базовый Стандарт 3DТрекинга Объектов в Реальном Времени

## Описание
Официальная реализация системы 3D Multi-Object Tracking (MOT), представленная на IROS 2020. Репозиторий предлагает "простой, но точный" baseline для трекинга объектов с использованием данных LiDAR (облака точек). Система использует 3D-детектор объектов для получения ориентированных 3D-боксов и связку 3D Kalman Filter + Hungarian Algorithm для оценки состояния и ассоциации данных. Скорость работы — 214.7 FPS (в 65 раз быстрее конкурентов).

## Основные Разделы
1. **Introduction** — философия "Accuracy vs Complexity" (фокус на простоте и скорости).
2. **Installation** — мануал по настройке окружения для работы с KITTI и nuScenes датасетами.
3. **Benchmarking** — воспроизведение результатов на стандартных лидербордах.
4. **ROS Integration** — поддержка реального времени через Robotic Operating System.
5. **Metrics (sAMOTA)** — введение новых метрик для оценки точности 3D трекинга.

## Почему это Killer-App
- **Speed King** — 214+ FPS делает систему пригодной для беспилотных автомобилей и быстрых дронов.
- **Simplicity** — доказательство того, что классические алгоритмы (Kalman + Hungarian) все еще доминируют при правильной реализации.
- **State-of-the-art** — удерживает лидирующие позиции по точности при минимальных вычислительных затратах.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Robotics Perception Nucleus — основной алгоритм для NEXUS Robotics агента (траектории, избегание препятствий).
- **Интеграция:** Модуль предикции (Kalman Filter) может быть адаптирован для предсказания изменений в графах данных (Data Flow Tracking).
- **Ключевое:** Использование sAMOTA метрик для обучения NEXUS Vision агентов.

## Топ-3 инсайта
- 3D-трекинг значительно точнее 2D-проекций за счет учета глубины и ориентации.
- Использование стандартного детектора (off-the-shelf) позволяет фокусироваться только на логике движения.
- Минимальная задержка (latency) — критический фактор безопасности в автономных системах.
