# 🧬 RL-MATH-FOUNDATIONS: Decision Intelligence Base

Математический фундамент обучения с подкреплением. Источник генов для **автономного принятия решений и стратегий адаптивного поведения**.

## 🕹 Генетический Профиль
- **Bellman Optimality Engine**: Универсальная матричная логика для поиска оптимального пути в сложных графах состояний.
- **Temporal Difference (TD) Learning**: Гены обучения "в процессе", позволяющие агентам обновлять свою модель мира без ожидания финального результата.
- **Actor-Critic Structures**: Архитектурный паттерн разделения исполнителя (Actor) и оценщика (Critic).

## 🛠 Применение в NEXUS
- **Strategic Planner Agent**: Синтез агентов для управления ресурсами и долгосрочного планирования.
- **Adaptive Navigator**: Навигация в динамически изменяющихся информационных полях (RAG-динамика).
