# 🧬 CAUSALML: Reasoning & Causality DNA

Библиотека Uber для каузального машинного обучения. Источник генов для **понимания причинно-следственных связей**.

## 🕹 Генетический Профиль
- **Uplift Modeling Engine**: Оценка реального влияния конкретного действия на результат (обработка "Counterfactuals").
- **Treatment Effect Selection**: Алгоритмы выбора оптимального воздействия для достижения цели.

## 🛠 Применение в NEXUS
- **Strategic Decision Support**: Анализ последствий различных сценариев развития событий для оркестратора NEXUS.
- **Agent Reward Optimization**: Тонкая настройка систем вознаграждения агентов на основе анализа их реального вклада.
