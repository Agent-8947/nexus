# ACM-ICPC-ALGORITHMS — Фундаментальная Библиотека Алгоритмов Спортивного Программирования

## Описание
Коллекция критически важных алгоритмов и структур данных, используемых в мировом олимпиаде программирования ACM-ICPC. Репозиторий охватывает практически все области: от базового обхода графов до сложных потоковых сетей и математических алгоритмов. Код представлен на нескольких языках (C++, Java, Python, Kotlin), что делает его универсальным справочником.

## Основные Разделы
1. **Dynamic Programming (DP)** — задачи о рюкзаке, LCS, LIS, монеты, палиндромы.
2. **Graph Algorithms** — Дейкстра, Краскал, Прим, поиск мостов, топологическая сортировка.
3. **Data Structures** — Fenwick Tree, Segment Tree, Disjoint Set, Red-Black Tree, Treap, Trie.
4. **Mathematical Algorithms** — тест Миллера-Рабина, решето Эратосфена, Convex Hull, биномиальные коэффициенты.
5. **Network Flow** — алгоритмы Диница, Эдмондса-Карпа, Форда-Фалкерсона.
6. **String Algorithms** — KMP, Hamming Distance, анаграммы, разбор арифметических выражений.

## Почему это Killer-App
- **Comprehensive Coverage** — "библия" алгоритмов для любого разработчика.
- **Polyglot Implementation** — примеры на современных языках программирования.
- **Competitive Tested** — алгоритмы оптимизированы по памяти и времени для прохождения жестких тестов олимпиад.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Algorithmic Core — библиотека базовых функций для NEXUS Code Synthesis агентов.
- **Интеграция:** Агенты могут использовать этот репо как "словарь решений" при генерации оптимизированного кода.
- **Ключевое:** Сегмент `Network Flow` критичен для NEXUS при расчете пропускной способности каналов данных.

## Топ-3 примера (NEXUS focus)
- **Segment Tree:** эффективное обновление и запрос на интервалах (мониторинг логов).
- **Disjoint Set (Union-Find):** анализ связности в графе зависимостей.
- **Trie (префиксное дерево):** сверхбыстрый поиск по базе токенов или секретов.
