# 🧬 BANDIT: Security Intelligence Gene

Инструмент статического анализа безопасности кода Python. В экосистеме NEXUS является критическим источником генов для **автоматического аудита безопасности** всех разрабатываемых агентов.

## 🕹 Генетический Профиль
- **AST Security Scanning**: Глубокий анализ кода на уровне синтаксического дерева.
- **Vulnerability Signatures**: Набор паттернов для обнаружения инъекций, слабых шифров и хардкода.

## 🛠 Применение в NEXUS
- **Security Sentinel**: Автоматическая проверка каждого `synthesized_agent.py` перед деплоем.
- **Nexus Auditor**: Сканирование всей инфраструктуры NEXUS на наличие архитектурных уязвимостей.
