# 98.CSS — Дизайн-система Windows 98 для Web

## Описание
Легковесная CSS-библиотека (без JavaScript), превращающая стандартные HTML-элементы в аутентичные интерфейсы эпохи Windows 98. Фокусируется на пиксельной точности (pixel-perfect) границ, градиентов и шрифтов. Идеально подходит для создания ретро-дашбордов, ностальгических приложений или специализированных внутренних инструментов (Internal Tools) с уникальной эстетикой.

## Основные Разделы
1. **Windows & Dialogs** — классические окна с заголовками, кнопками сворачивания/закрытия.
2. **Buttons & Controls** — 3D-кнопки (active/inactive), чекбоксы, радиокнопки, выпадающие списки.
3. **Forms & Inputs** — текстовые поля с инсет-границами (sunken style).
4. **Tabs & Sliders** — навигационные вкладки и ползунки громкости/яркости.
5. **Typography** — использование MS Sans Serif (или аналогов) для 100% сходства.

## Почему это Killer-App
- **No JS Dependency** — работает с любым фреймворком (React, Vue, Svelte) или вообще без них.
- **Semantic HTML** — использует стандартные теги (`button`, `input`, `div`), стилизуя их через классы.
- **Micro-size** — минимизированный CSS весит копейки, не нагружая страницу.
- **Aesthetic Authority** — "золотой стандарт" ретро-интерфейсов на GitHub.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Specialized UI Skin — может использоваться для создания "секретных" или имитационных дашбордов NEXUS (Stealth Mode).
- **Интеграция:** NEXUS Orchestrator Dashboard может иметь переключатель в "Classic Mode" на базе 98.css.
- **Ключевое:** Идеальный пример того, как через чистый CSS достичь сложного визуального эффекта (pixel-perfect boundaries).

## Пример реализации
```html
<div class="window" style="width: 300px">
  <div class="title-bar">
    <div class="title-bar-text">NEXUS Oracle v1.0</div>
    <div class="title-bar-controls">
      <button aria-label="Minimize"></button>
      <button aria-label="Close"></button>
    </div>
  </div>
  <div class="window-body">
    <p>System status: INOPERABLE (just kidding)</p>
    <button>OK</button>
  </div>
</div>
```
