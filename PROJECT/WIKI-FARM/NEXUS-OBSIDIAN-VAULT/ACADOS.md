# ACADOS — Высокоскоростной Солвер для Нелинейного Оптимального Управления

## Описание
Высокопроизводительный программный комплекс на языке C, предназначенный для решения задач нелинейного программирования (NLP) со структурой оптимального контроля (OCP). Оптимизирован для встраиваемых систем и приложений реального времени, таких как Model Predictive Control (MPC) и Moving Horizon Estimation (MHE). Используется в беспилотниках, робототехнике (движение ног, манипуляторы) и энергетических системах.

## Основные Разделы
1. **NMPC & MHE** — реализация управления и оценки состояния в реальном времени.
2. **DAE Support** — поддержка дифференциально-алгебраических уравнений.
3. **Multiple Shooting Method** — метод временной дискретизации для быстрых и робастных решений.
4. **Integration with RL** — возможность использования MPC солвера как дифференцируемого слоя в нейросетях.
5. **High-Performance Solvers** — использование HPIPM для эффективного решения квадратичного программирования (QP).

## Почему это Killer-App
- **Embedded-First** — минимальный оверхед, идеален для микроконтроллеров и бортовых компьютеров.
- **Extreme Efficiency** — эксплуатирует специфическую структуру OCP для достижения максимальной скорости.
- **Modular Architecture** — позволяет свободно комбинировать солверы, интеграторы и методы глобализации.
- **Industry Standard** — используется в таких проектах, как `openpilot` (система помощи водителю).

## Архитектурная Ценность для NEXUS
- **Паттерн:** Real-Time Controller — основной вычислительный движок для NEXUS-агентов, управляющих физическими или критическими цифровыми процессами.
- **Интеграция:** Модуль `CasADi` для символьного описания проблем стыкуется с NEXUS Semantic DNA для генерации математических моделей.
- **Ключевое:** Поддержка DAE позволяет NEXUS моделировать сложные системы с ограничениями (например, экономические или юридические потоки как динамические системы).

## Топ-3 примера применения
- Robotics: Контроль равновесия двуногих роботов.
- Aerospace: Оптимизация траектории дронов с изменяемой геометрией крыла.
- Autonomous Vehicles: Управление рулевым механизмом и скоростью в openpilot.
