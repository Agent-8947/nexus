# 🧬 BASE-UI: Headless Interaction Patterns

Библиотека безстилевых компонентов с фокусом на доступность. Генетический источник для **интерфейсов взаимодействия агентов**.

## 🕹 Генетический Профиль
- **Accessible Interaction Primitives**: Стандартизированная логика навигации и фокуса (WAI-ARIA).
- **State UI Abstraction**: Чистая логика поведения компонента, отделенная от его визуального представления.

## 🛠 Применение в NEXUS
- **Nexus Dashboard**: Использование примитивов Base UI для создания адаптивных и доступных панелей управления.
- **Agent UI Primitives**: Генерация интерфейсов, которые "подстраиваются" под среду вывода (Desktop/Web/CLI).
