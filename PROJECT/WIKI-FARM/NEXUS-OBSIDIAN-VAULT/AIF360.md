# AI FAIRNESS 360 (AIF360) — Инструментарий для Обеспечения Справедливости ИИ

## Описание
Расширяемая библиотека с открытым исходным кодом, разработанная IBM Research для обнаружения и смягчения нежелательной предвзятости (bias) в моделях машинного обучения. AIF360 предоставляет комплексный набор метрик для проверки наборов данных и моделей, а также современные алгоритмы дебиасинга (debiasing) для всех этапов жизненного цикла ИИ-приложения.

## Основные Разделы
1. **Bias Detection Metrics** — более 70 метрик справедливости (Statistical Parity Difference, Equal Opportunity Difference и др.).
2. **Bias Mitigation Algorithms** — алгоритмы предварительной обработки (Reweighing), промежуточной обработки (Adversarial Debiasing) и пост-обработки.
3. **Explainability Integrated** — инструменты объяснения того, почему тот или иной показатель метрики указывает на наличие предвзятости.
4. **Interactive Experience** — веб-интерфейс для ознакомления концепциями справедливости на реальных данных.

## Почему это Killer-App
- **Scientific Rigor** — алгоритмы основаны на рецензируемых исследованиях ведущих университетов и IBM.
- **Full Lifecycle Support** — позволяет бороться с предвзятостью как в исходных данных, так и в финальных предсказаниях.
- **Extensibility** — архитектура позволяет легко добавлять новые кастомные метрики и алгоритмы.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Ethical AI Guardrail — критический модуль для NEXUS Governance агентов, обеспечивающий соответствие алгоритмов юридическим и этическим нормам.
- **Интеграция:** Применение метрик AIF360 при мутации NEXUS DNA для исключения дискриминационных паттернов.
- **Ключевое:** Использование `Adversarial Debiasing` для создания "непредвзятых" поисковых агентов (OSINT).

## Поддерживаемые Алгоритмы (Snapshot)
- **Optimized Preprocessing:** Модификация данных до обучения.
- **Reject Option Classification:** Изменение классификации вблизи границ принятия решения.
- **Equalized Odds Postprocessing:** Коррекция предсказаний для выравнивания точности по группам.
