# ALPHAZERO-GOMOKU — Обучение AlphaZero для игры в Гомоку (Пять в Ряд)

## Описание
Практическая реализация алгоритма AlphaZero для классической настольной игры Гомоку (Gomoku). В отличие от Go или шахмат, Гомоку достаточно проста для того, чтобы натренировать сильную ИИ-модель на обычном ПК всего за несколько часов. Проект фокусируется на схеме обучения через самообучение (self-play) и демонстрирует эффективность архитектуры без использования экспертных знаний человека.

## Основные Разделы
1. **Self-Play Training Loop** — ядро системы, где агент играет сам с собой для накопления опыта.
2. **MCTS (Monte Carlo Tree Search)** — алгоритм поиска в дереве состояний для принятия решений.
3. **Policy-Value Network** — нейронная сеть, предсказывающая как вероятность ходов (policy), так и оценку позиции (value).
4. **Multiple Frameworks** — поддержка обучения на PyTorch, TensorFlow и Theano/Lasagne.

## Почему это Killer-App
- **Simplicity & Speed** — идеальный проект для понимания AlphaZero без необходимости в вычислительных мощностях Google.
- **Cross-Framework** — позволяет сравнить производительность и удобство реализации на разных DL-библиотеках.
- **Educational Tool** — чистый код, реализующий сложные концепции (MCTS, AlphaGo Zero) в доступной форме.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Self-Evolving Strategist — NEXUS может использовать этот подход для обучения своих агентов "стратегическому планированию" в игровых или симуляционных средах.
- **Интеграция:** Применение `MCTS` для оптимизации выбора путей выполнения миссий у автономных агентов.
- **Ключевое:** Возможность обучения модели 6x6 за 2 часа делает проект пригодным для динамического обучения NEXUS-агентов под конкретные задачи.

## Параметры обучения (Benchmarks)
- **6x6 Board (4 in a row):** Около 500–1000 партий (2 часа на ПК).
- **8x8 Board (5 in a row):** Около 2000–3000 партий (около 2 дней на ПК).
