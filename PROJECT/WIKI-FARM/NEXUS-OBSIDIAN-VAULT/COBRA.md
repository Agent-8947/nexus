# 🧬 COBRA: Security Auditing DNA (Static Analysis)

Инструмент для статического анализа и аудита безопасности исходного кода. Источник генов для **поиска уязвимостей в коде программ**.

## 🕹 Генетический Профиль
- **Muti-language Rule Engine**: База правил для обнаружения SQL-инъекций, XSS и небезопасных зависимостей в PHP, Java и других языках.
- **Vulnerability Scanning Logic**: Алгоритмы обхода дерева исходного кода для выявления потенциально опасных конструкций.

## 🛠 Применение в NEXUS
- **Security Guard Rails**: Автоматический аудит всего кода, генерируемого агентами NEXUS, перед его выполнением.
- **Legacy Code Inspection**: Быстрая проверка "грязного" кода из сторонних репозиториев на наличие бэкдоров.
