# ABRACADABRA (魔曰) — Система Скрытого Шифрования под Видом Древнекитайской Прозы

## Описание
Уникальный инструмент стенографического шифрования, который превращает любые данные в текст, имитирующий классическую китайскую литературу (文言文 - вэньянь). Использует AES-256 для базовой защиты, дополняя её сложными механизмами синтаксического синтеза предложений на основе 3000 самых частотных иероглифов. Результат выглядит не как "мусор" или шифротекст, а как аутентичный древний текст, что обеспечивает высочайший уровень обфускации.

## Основные Разделы
1. **Simulation Encryption** — генерация текста с соблюдением грамматики и стиля классических трактатов.
2. **Advanced Crypto Suite** — поддержка HMAC-SHA256, PBKDF2 (100k итераций), TOTP и Strong IV.
3. **Triple Rotor Confusion** — имитация работы роторных машин для перемешивания маппинга символов.
4. **Intelligent Compression** — алгоритмы Unishox2 (для коротких текстов) и GZIP.
5. **Cross-Platform** — Web App, Chrome/Edge/Firefox расширения, Android клиент.

## Почему это Killer-App
- **High Obfuscation** — текст проходит визуальную проверку "на человечность", в отличие от Base64.
- **Triple Security** — Сжатие -> AES256 -> Роторная путаница -> Маппинг иероглифов.
- **Open Source Security** — проект полностью открыт, прошел тесты и аудит сообщества.
- **Cultural Blend** — сочетание современных крипто-стандартов с эстетикой Древнего Китая.

## Архитектурная Ценность для NEXUS
- **Паттерн:** Stealth Communication — основа для скрытого обмена данными между NEXUS-агентами через публичные каналы (Discord/Telegram).
- **Интеграция:** Может использоваться для "сокрытия" конфиденциальных конфигов внутри Markdown-документации.
- **Ключевое:** Использование `Unishox2` критично для оптимизации хранения малых объемов данных в NEXUS DNA.
