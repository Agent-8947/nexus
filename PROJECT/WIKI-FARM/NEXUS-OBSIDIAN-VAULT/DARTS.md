# 🧬 DARTS: Predictive Vision DNA

Библиотека, делающая прогнозирование будущего (временных рядов) простым и точным. Источник генов для **предсказательной аналитики**.

## 🕹 Генетический Профиль
- **Unified Forecasting Interface**: Гены стандартизации, позволяющие менять классический ARIMA на мощный TCN (Temporal Convolutional Network) одной строчкой кода.
- **Anomaly Detection Stream**: Механизмы обнаружения отклонений в потоке данных, критичные для мониторинга здоровья систем NEXUS.

## 🛠 Применение в NEXUS
- **Resource Load Forecasting**: Предсказание нагрузки на ферму серверов и автоматическое масштабирование.
- **Security Anomaly Hunter**: Анализ логов доступа и выявление подозрительных паттернов поведения через гены `QuantileDetector`.
