# 🧬 DOCLING: Document Reconstruction DNA (IBM)

Инструмент, превращающий хаос сложных документов в чистые данные. Источник генов для **реконструкции структуры знаний**.

## 🕹 Генетический Профиль
- **Visually-Augmented Parsing**: Использование зрения для понимания того, где в документе находятся таблицы и как они связаны с текстом.
- **Lossless JSON Export**: Гены сохранения полной структуры документа при конвертации, что критично для "понимания" документов ИИ-агентами.

## 🛠 Применение в NEXUS
- **Legal Doc Analyzer**: Разбор сложных многостраничных контрактов и законов в Obsidian-доксерии с сохранением иерархии.
- **Formula & Table Recovery**: Извлечение математических данных из PDF-статей для обучения экспертных систем.
